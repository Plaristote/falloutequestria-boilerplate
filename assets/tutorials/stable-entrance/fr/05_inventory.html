Votre peuple ne vous enverrait pas à l'aventure dans la nature sans aucun moyen de défense. Selon les spécialités que vous avez choisies pour votre personnage, vous devriez avoir reçu de l'équipement.

Ouvrons l'inventaire pour voir ce dont vous disposez. Appuyez sur la touche I ou cliquez sur le bouton INV pour ouvrir votre inventaire.

Lorsque vous cliquez sur un objet du côté gauche, une nouvelle section apparaît, affichant une description de l'objet ainsi que certaines actions que vous pouvez effectuer directement depuis l'inventaire. Si vous êtes blessé, vous voudrez peut-être utiliser une potion de soin :

Voyons maintenant comment équiper votre personnage. Les emplacements d'utilisation rapide sont ceux dont vous aurez besoin pour utiliser des objets pendant les combats. Selon vos spécialités, votre inventaire devrait contenir soit une arme à feu, soit un couteau. Faites glisser cet objet dans l'un des emplacements d'utilisation :

Voilà : vous pouvez maintenant utiliser cet objet pour combattre.
