Les deux rectangles gris au centre du HUD affichent les actions rapides actuellement disponibles.

C'est ce que nous appelons le HUD :

Comme vous n'avez actuellement aucun objet équipé, vos deux actions rapides sont des attaques au corps à corps. Vous pouvez les utiliser pour tuer les rats :

Placez-vous à côté de l'un des rats. Cliquez ensuite sur l'une des actions rapides pour l'activer. Le rat devrait alors être surligné en rouge. Déplacez le curseur au-dessus du rat à côté de vous : un pourcentage devrait apparaître. Il indique vos chances de réussite. Cliquez sur le rat pour déclencher l'action.

Coût en points d'action
Le nombre de points d'action qui seront dépensés lors de l'utilisation d'une action est affiché en bas à droite du bouton d'utilisation rapide.

Modes d'utilisation
Certains objets peuvent être utilisés de différentes manières (par exemple, le rechargement pour une arme à feu). Vous pouvez faire défiler les différents modes d'utilisation disponibles en faisant un clic droit sur le bouton d'utilisation rapide.
